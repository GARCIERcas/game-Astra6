# ASTRA-6

Пиксельный авиасимулятор с видом из шлема. Можно пройти восемь воздушных ворот над горной долиной или выбрать свободный полёт.

## Запуск

Требуются Node.js 24 и браузер с WebGL2.

```sh
npm ci
npm run dev
```

Продакшен-сборка создаётся командой `npm run build` в каталоге `dist`. Команда `npm run preview` запускает её локально. При отправке в main GitHub Actions собирает и публикует игру через GitHub Pages.

## Управление

| Клавиши | Действие |
|---|---|
| W / S или ↑ / ↓ | Нос вниз / вверх |
| A / D или ← / → | Крен |
| Q / E | Рыскание |
| Shift / Ctrl | Увеличение / уменьшение тяги |
| Пробел | Начать или приостановить полёт |

## Устройство

- `src/flight.ts` — интегратор с шагом 1/120 с, ориентация в пространстве, вектор скорости, тяга, тяжесть, подъёмная сила и сопротивление. Аэродинамика игровая, с приближённой зависимостью от угла атаки.
- `src/world.ts` — процедурный рельеф, маршрут, векторная математика.
- `src/render.ts` — низкоразрешённый WebGL2-рендерер, шейдер неба, геометрия долины.
- `src/hud.ts` — индикация шлема, проекция ворот и графика кабины.
- `src/main.ts` — ввод, игровой цикл, интерфейс и синтез звука.
